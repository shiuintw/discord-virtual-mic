## RVC Voice Models

The app scans `models/**/*.pth` and shows discovered models in the Voice Model
dropdown. `models/god_tone/god_tone_rvc.pth` will appear automatically.
Use `Test(EN)` or `Test(ZH-TW)` to preview the selected voice model through your
default speaker output before sending it to the virtual microphone.
Use `Transpose` to shift the pitch before RVC conversion. For female TTS voices
converted into a male RVC model, start around `-12` semitones and adjust by ear.

RVC inference uses a separate Python 3.10 virtual environment because the RVC
dependency stack is not compatible with every Python version.

```commandline
python3.10 -m venv .venv-rvc
.venv-rvc/bin/pip install pip==24.0
.venv-rvc/bin/pip install -r requirements-rvc.txt
```

After `.venv-rvc` is installed, selecting an RVC model in the dropdown will
automatically run `scripts/rvc_infer.py`.

You can override the built-in backend with `RVC_INFER_COMMAND`. The command can
use these placeholders:

* `{input}`: temporary source wav generated by TTS
* `{output}`: target wav path that your RVC command must create
* `{model}`: selected `.pth` model path
* `{pitch}`: transpose value in semitones

Example:

```commandline
export RVC_INFER_COMMAND='your-rvc-command --input "{input}" --output "{output}" --model "{model}"'
python src/main.py
```
